# Ветка python-telegram-bot

Сохраняйте `Application`, обработчики и lifecycle существующего проекта. В современных async-версиях не используйте старые синхронные примеры с `Updater` как универсальный шаблон.

Для `ConversationHandler` проверьте требования к порядку обработки updates и выбранные настройки concurrency. Согласуйте `per_chat`, `per_user`, `per_message` и persistence с продуктовым сценарием. При подключении к существующему event loop выбирайте подходящий lifecycle, а не вкладывайте `run_polling()` в уже запущенный цикл.

Регистрируйте обработчик ошибок; различайте сетевой сбой, ошибку Bot API и исключение прикладной операции. В тестах используйте транспорт и модели именно установленной версии.

Источник: [python-telegram-bot](https://docs.python-telegram-bot.org/en/stable/). Для старой версии переключи документацию на соответствующую ветку.
