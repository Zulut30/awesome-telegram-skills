# Ветка python-telegram-bot

Сохраняй `Application`, обработчики и lifecycle существующего проекта. В современных async-версиях не используй старые синхронные примеры с `Updater` как универсальный шаблон.

Для `ConversationHandler` проверь требования к порядку обработки updates и выбранные настройки concurrency. Согласуй `per_chat`, `per_user`, `per_message` и persistence с продуктовым сценарием. При подключении к существующему event loop выбирай подходящий lifecycle, а не вкладывай `run_polling()` в уже запущенный цикл.

Регистрируй обработчик ошибок; различай сетевой сбой, ошибку Bot API и исключение прикладной операции. В тестах используй транспорт и модели именно установленной версии.

Источник: [python-telegram-bot](https://docs.python-telegram-bot.org/en/stable/). Для старой версии переключи документацию на соответствующую ветку.
