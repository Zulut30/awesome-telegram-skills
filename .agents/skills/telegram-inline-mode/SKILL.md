# Inline mode

Различай inline query и callback query. Определи продуктовый сценарий: найти и отправить результат в чат либо перейти в личный диалог. Проверь настройку inline mode у бота и типы результатов, доступные в установленном SDK.

## Обработка поиска

Нормализуй запрос, ограничь нагрузку на поисковый backend и задай таймаут. Для пустого запроса выбери полезное стартовое состояние, если это соответствует продукту. Не раскрывай закрытые данные только потому, что пользователь знает идентификатор объекта.

Пагинация должна иметь устойчивый cursor, связанный с текущим запросом и его контекстом. Поддельный или просроченный offset не должен открывать чужой результат или приводить к необработанному исключению.

Идентификатор результата должен быть устойчивым и соответствовать отправляемому объекту. Содержимое сообщения формируй отдельно от заголовка и превью; безопасно форматируй пользовательские данные. Проверь актуальные ограничения количества и размера результатов в API.

## Кеш и приватность

Если выдача зависит от пользователя или его прав, настрой персональный кеш и подходящий срок. Не позволяй общему кешу смешивать персональные результаты. Изменение прав доступа должно учитываться политикой кеширования.

При необходимости учета выбранных результатов проверь настройку feedback. Отсутствие такого события не доказывает, что сообщение не было отправлено.

## Проверка

Проверь пустой запрос, обычный поиск, следующую страницу, неверный cursor и отправку результата в реальный чат на тестовом боте. Для персональных данных проведи сценарий с двумя пользователями. Укажи, какие настройки BotFather нужны и какие проверены.
