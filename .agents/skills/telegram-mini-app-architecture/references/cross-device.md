# Архитектура для разных размеров

Измеряйте доступную ширину и высоту Mini App. Desktop Telegram может открыть узкое окно, планшет — небольшой split view. Platform помогает выбирать capabilities, но не заменяет размер контейнера.

| Контекст | Компоновка по содержимому |
| --- | --- |
| Узкий телефон/окно | Вертикальная форма, понятный путь и видимые следующие действия |
| Планшет/split view | Несколько колонок там, где помещаются; touch остается доступным |
| Широкий desktop | Ограниченная ширина текста/формы; обзор или панель по пользе для задачи |
| Landscape/малая высота | Прокрутка, ограниченная высота overlay, достижимые CTA и focused input |

Breakpoints выбирайте там, где содержимое перестает помещаться. Не держите расходящиеся версии одного действия для desktop/mobile. Master/detail может перестраиваться из двух панелей в последовательные экраны с сохраненным выбором.

Shell централизует insets и scrolling. Внутренний компонент получает безопасную область. Для native MainButton учитывайте доступное пространство клиента, для CTA страницы — его фактическую высоту в scrolling контенте. Не резервируйте два footer для одного действия.

## Приемочная матрица

Это исходные профили в CSS px, а не обещание проверки физических устройств:

| Профиль | Размеры | Наблюдение |
| --- | --- | --- |
| Компактный | 320×568, 390×844 | Переносы, отсутствие общего горизонтального scroll, полный путь |
| Планшет | 768×1024, 1024×768 | Полезная ширина, touch, rotate без сброса формы |
| Desktop | 1280×800, 1536×864 | Ширина формы, клавиатура, focus |
| Узкое desktop-окно | 480×720 | Реакция на WebView вместо device detection |
| Малая видимая высота | 390×420 | Прокрутка к полю/CTA; приближение клавиатуры |

Применяйте светлую и темную темы к релевантным экранам. На компактном профиле проверьте длинное имя, заголовок, увеличенный текст и error message. Reflow при zoom не должен терять действие.

Инварианты: scrollWidth страницы не превышает clientWidth; контент не скрывается overlay; поле можно сфокусировать и завершить действие; back/resize сохраняют ввод; повтор CTA не создает вторую операцию. Скриншота кнопки недостаточно — проверьте достижимость и нажатие.

Сохраните screenshots компактного и широкого состояния, viewport/theme, build/version и результаты действий. Эмуляция размера, safe-area mock и уменьшение высоты не проверяют Telegram bridge, native-клавиатуру, notch и скорость физического устройства. Для заявленных клиентов нужна отдельная runtime-проверка.

Источник: [Telegram Design Guidelines](https://core.telegram.org/bots/webapps#design-guidelines). Матрица и компоновки — критерии набора, адаптируемые к продукту.
