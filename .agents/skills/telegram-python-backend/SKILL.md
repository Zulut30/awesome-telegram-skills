# Python backend

Изучи текущий web-framework, ORM/driver, schema и способ подтверждения личности. Сохраняй выбранный стек; FastAPI и SQLAlchemy — возможные варианты, а не обязательная миграция. Backend и бот используют одни прикладные правила и источник данных.

## Контракт и права

Опиши вход, результат, ошибки и переход состояния одной операции. Личность приходит из проверенной серверной сессии/adapter, а не user_id, цены или роли в body. Проверяй доступ к объекту и разрешенный переход при каждом действии. CORS и наличие Telegram bridge не являются авторизацией.

Используй runtime validation для внешнего JSON, bounded pagination и ограничения входных данных по смыслу продукта. Отдели transport модели от ORM; не выдавай внутренние колонки и исключения. При существующей OpenAPI схеме сохраняй ее совместимость с TypeScript-клиентом; breaking change делай явным.

## Хранение и операции

При изменении записей, конкурентных действий или миграций прочитай [references/persistence.md](references/persistence.md). Задай границу транзакции, ограничения БД и политику повторного запроса. Не подменяй durable correctness локальным asyncio.Lock или кешем процесса.

Синхронный DB/HTTP вызов не становится неблокирующим внутри async def. Используй подходящий driver/framework execution model. Session/transaction принадлежит запросу либо отдельной задаче, не разделяется между конкурентными задачами. У внешних вызовов есть timeout и определенное поведение при неизвестном результате.

## Миграции и проверка

Используй миграции проекта, проверь сгенерированный SQL и совместимость существующих строк. Проверь чистую БД и переход с предыдущей схемы во временной среде. Не запускай destructive migration в рабочей БД как проверку разработки.

Проверь прикладной результат через API: собственный/чужой объект, недопустимое состояние, конкурентное создание, повтор, rollback и перезапуск. Используй реальную целевую БД там, где mock или другая СУБД скрывает риск; явно укажи ограничения локального probe. Сохрани команды запуска, schema/API изменения и фактические результаты.

Источники: [FastAPI async](https://fastapi.tiangolo.com/async/), [SQLAlchemy asyncio](https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html), [PostgreSQL INSERT](https://www.postgresql.org/docs/current/sql-insert.html), [Alembic autogenerate](https://alembic.sqlalchemy.org/en/latest/autogenerate.html). Используй документацию версии проекта.
