# Формы, покупка и восстановление

## Контракт перехода

Для каждого существенного перехода определи вход/контекст, действие, данные, серверную проверку, результат и возврат. Например, запись: услуга → слот → контакты → обзор → серверное подтверждение. Это пример, а не обязательные пять экранов.

Deep link к отмененной записи показывает ее действительный статус и доступные действия. Отсутствующий объект и чужой объект не раскрывают лишние сведения. Повторное открытие checkout не сбрасывает оплаченный заказ в черновик.

## Форма

Свяжи label, подсказку и ошибку с полем. Required обозначается словами/семантикой; placeholder не заменяет label. Ошибку показывай после осмысленной проверки, избегая постоянного объявления на каждый символ. Сохраняй допустимые поля после неуспешной отправки.

В длинной форме полезны логические группы и понятный прогресс. Короткую форму не дели на шаги ради самой пошаговости. Back сохраняет значения, доступные варианты перепроверяются при необходимости. Пропавший слот нельзя подтверждать только по старому UI.

После отправки с ошибками дай связанное описание и осмысленный focus на summary/первое поле. После успешного перехода объяви новый контекст; не перехватывай focus при каждом обновлении цены или таймера.

## Checkout

Перед действием видны товар, итог, валюта, период и наличие автопродления по фактической модели. Отмена продления и возврат покупки объясняются отдельно. Pending исключает повторное действие UI, однократный эффект обеспечивает backend.

Timeout после отправки не означает отказ: покажи «проверяем результат», запроси состояние сохраненного заказа, затем предложи допустимый повтор. Закрытие native invoice само по себе не подтверждает выдачу доступа.

## Приемка

Пройди deep link/первый вход, корректировку выбора, ошибку поля, пустые данные и неизвестный результат. Сверь доступность CTA при длинном тексте и малой высоте. Измеряй время/ошибки только при реально проведенном наблюдении; не придумывай улучшение conversion.

Источники сверены 3 октября 2026 года: [многостраничные формы](https://www.w3.org/WAI/tutorials/forms/multi-page/), [уведомления и ошибки формы](https://www.w3.org/WAI/tutorials/forms/notifications/), [Telegram Mini Apps](https://core.telegram.org/bots/webapps). Число шагов и метод приемки выбираются по продукту.
