# Выбор библиотек

Сначала установи API-плоскость: Bot API, MTProto, WebApp bridge или API платежного провайдера. Прочитай [references/libraries.md](references/libraries.md) как карту кандидатов, а не обязательный список установки.

Для существующего проекта сохраняй выбранную библиотеку. Сопоставь нужные методы и поля с моделями реально установленной версии, release notes и исходниками. Версия Bot API на сайте не доказывает поддержку SDK.

Для нового проекта оцени async/sync-модель, поддерживаемый Python/runtime, lifecycle, состояние поддержки, release cadence, transport и способ обновления. Выбери одну библиотеку на конкретную роль и обоснуй ее нужной функцией, а не количеством звезд.

Различай официальный API, официальный SDK сервиса и wrapper сообщества. Если официальный SDK синхронный, его прямой вызов из async-handler может блокировать процесс: выбери управляемое выполнение или HTTP-клиент согласно проекту.

Проверь происхождение пакета через документацию и upstream; похожее имя пакета не доказывает принадлежность поставщику. Не устанавливай непроверенный SDK из поисковой выдачи. Миграция должна учитывать сохраненные sessions, handlers и breaking changes, а не только изменение imports.

Результат: выбор и причина, конкретная совместимая версия, минимальные зависимости, неподдерживаемые функции и проверенная альтернатива. При реализации подтверди imports, типы и фактическую сериализацию нового поля.
