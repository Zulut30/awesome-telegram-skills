# Проверка подключения библиотеки агентом

6 октября 2026 года проверен путь из [инструкции для агента](for-agents.md) на принятой версии **0.24.0**. Проверка использует реальные локальные wheel/tarball и один перенесенный скилл; runtime imports разрешаются в установленные пакеты, а не в source checkout.

## Сценарии и результат

| Вход / задача | Выполненная проверка | Результат |
| --- | --- | --- |
| Передан один `telegram-code-patterns` | Dry-run не пишет файлы; копируется только один каталог; проверены 305 локальных Markdown references; повторная установка сохраняет прежние файлы | Прошел |
| Найти две кнопки в ряд | Буквальные команды `recipes`, `recipes --show`, `run-recipe`, `run-recipe --offline` из инструкции | Поиск и код доступны; plan отделен от исполнения; fixture прошла без Telegram-запросов |
| Использовать точный Python import | `ActionButton`, `action_menu` из установленного aiogram extra; четыре кнопки дают два ряда по две | Прошел; пакет 0.24.0, aiogram 3.31.0 |
| Использовать core без SDK | Новый venv с wheel и `--no-deps`; aiogram отсутствует; core import работает; SDK-рецепт сообщает `aiogram-extra-required` | Прошел |
| Проверить авторизацию Mini App | Публичный `validate_init_data`: synthetic HMAC launch и отказ при неоднозначном `user` | Прошел; это подпись/freshness, не ACL или live login |
| Передан TypeScript tarball | Отдельный npm consumer, версия и CSS export, strict compilation value/type imports, bridge/native host composition, cleanup и отказ после dispose | Прошел без workspace imports |
| Агент путает `ref.*` с cookbook ID | `run-recipe ref.core_identity` | Контролируемый отказ; пример справочника читается отдельно |

17 операций/проверок сохранены локально в `output/pages-publication/agent-onboarding-report.json`; подробные логи находятся рядом. Это игнорируемые локальные артефакты, их отсутствие в clone не означает отсутствие инструкции или компонента.

Проверены wheel принятой поставки и заново собранный tarball с исправленным README (runtime API сохранен): wheel SHA256 `89be0aa3ea9e9d265d98be3e80ced9f0a06e72fda10239fe7bb37750f6ebafed`, tarball SHA256 `9903939ee0796f80d6cd9506880dec8f74595a875e448510124d1545dde6784c`. Hash описывает проверенные bytes; повторная локальная сборка проверяется заново.

## Что должен прочитать агент

`AGENTS.md` направляет к инструкции подключения. Один перенесенный скилл содержит собственный `references/agent-onboarding.md`, которому не нужен весь репозиторий. На сайте доступны `llms.txt`, машинные каталоги и точные imports, а полный `llms-full.txt` загружается по необходимости.

Для оценки решений агента используйте соответствующие сценарии [evaluation](evaluation.md), особенно сохранение текущего SDK/storage, ACL callback, unknown write и восстановление формы. Ожидаемый результат — выбранный публичный API, подтвержденная версия, интеграция в host и проверка существенного отказа; успешный import сам по себе недостаточен.

## Границы проверки

Это авторские исполняемые fixtures и проверка доступности инструкций. Независимый прогон другого ИИ-агента по скрытым заданиям здесь не выполнен; нельзя обещать, что любая модель правильно решит любую задачу. Live Telegram, платежные провайдеры и физические устройства этой проверкой не подтверждены. Статус библиотеки остается experimental.
