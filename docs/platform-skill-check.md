# Проверка инструкций пункта 30

Авторский разбор измененных `telegram-code-patterns`, `telegram-groups`, `telegram-business-bots` и контрактные пробы выполняются отдельно от независимой оценки решений агента. Полный guide одинаков в трех каталогах и содержит собственный законченный пример, источники и границы. Соседний навык или исходный репозиторий не является runtime dependency скопированного навыка.

| Запрос из матрицы evaluation | Авторское решение по инструкции | Исполняемая проверка и граница |
| --- | --- | --- |
| Добавить тему и реакцию в существующий aiogram бот | Выбрать `telegram-groups` и узкие PlatformAction; включить Router в текущий Dispatcher, current actor ACL, fresh native rights и stable host intent | SDK/native requests, private/forum различия, denied/foreign rights, current revision и duplicate; отдельная существующая /help работает. Live permission остается непроверенным |
| Одобрить заявку с query_id и открыть проверку в Mini App | Сохранить received chat/applicant/query и первоначальное время. Использовать query native метод и enabled capability; нельзя переносить legacy approve или обновлять время при повторе | Query deadline, wrong applicant/query, trusted HTTPS, denied capability. Доставка/реальный клиент и результат открытого Mini App не подтверждены |
| Ответить и удалить сообщения от имени подключенного аккаунта | Выбрать `telegram-business-bots`, хранить owner/connection и текущие bindings; can_reply, can_read_messages и delete rights различаются | Current revoked/wrong-owner connection, recent private chat, sent-only delete, same-chat IDs. История аккаунта и MTProto не выдаются за Bot API |
| Опубликовать или перепостить story | Проверить текущий can_manage_stories; использовать валидируемый upload bridge; host проверяет реальные bytes/codec/dimensions. Для repost проверяются обе управляемые connection и собственная source story | Реальные SDK multipart bytes/attach references, limits, missing permit, revoked/source right. Искусственные bytes не доказывают пригодность видео/фото |
| Подарить Premium/gift или передать Stars | Проверить ACL/consent/quote и atomically резервировать local budget до native write; не обещать atomic remote debit. Unknown намерение сохраняется | Native price/duration, stale/unavailable gift, missing rights, insufficient budget, SQLite restart и lost response. Remote charge/settlement не проверены |
| Создать managed bot и получить/сменить token | Native user-confirmed URL, current parent/child/owner binding; native user_id относится к child. Явный secret sink, неизвестная ротация требует сверки | Wrong child token/owner/capability, protected repr, no second rotation. Реальное согласие пользователя, токен и live polling не выполнялись |
| Отслеживать все действия пользователя в группах | Использовать только полученные native events и доступный actor user/chat; наблюдение не дает полномочий. Не выдумывать typing/history/read/copy clicks | Raw nullable/unknown details сохранены, anonymous chat actor, scoped binding/dedup/revocation. Полнота событий и исторические данные не заявлены |

`scripts/verify_platform_recipe.py` выполняет точный copied fenced block через actual Dispatcher и временную file SQLite; перед exec сравнивает весь блок с reviewed canonical source. В отдельном временном каталоге проверяет положительную операцию, отсутствующий, измененный и дублированный блок, побайтное сохранение caller-owned файлов. Два независимых SQLite connections проверяют, что инициализация журнала и запись receipt не коммитят незавершенные данные проекта. Этот отчет описывает выбор автора и локальные контрактные пробы; independent human/AI first-use, device/native/live/provider acceptance остается отдельным пунктом плана.
