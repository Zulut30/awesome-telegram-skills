# Первый запуск: исходный замер, пункт 020

Статус — в работе. Авторский AI-прогон установил предоставленный wheel 0.13.0 в новый внешний проект, создал offline-бота и выполнил Dispatcher/doctor. В `output/first-use-020-author-baseline` записано время инструментальных операций. Автор знаком с библиотекой, cache тёплый; эти секунды не являются временем новичка или независимым usability acceptance. Человеческих прогонов пока нет, targets не назначены.

## Две задачи для участника

1. Имея Python и предоставленный wheel, создайте нового offline-бота. Начните с README, найдите подходящее руководство; настоящего токена не используйте. Получите успешные /start, callback, закрытую SDK session и понятный doctor результат.
2. В существующем aiogram проекте добавьте клавиатуру с рядами 2/3/смешанной ширины. Выберите допустимые styles, убедитесь в fallback без подтверждённого entitlement; покажите serialized payload и integration check, сохранив SDK/Dispatcher проекта.

Начните таймер при чтении задания, остановите после проверки либо явного прекращения попытки. Отдельно запишите ожидание установки/tool операций, ошибки, места поиска, запросы помощи и итог. Не подсказывайте участнику найденный API до его попытки; помощь и прежнее знакомство отмечайте. Тесты автором не заменяют наблюдения участника.

Достаточен обезличенный текстовый результат: task ID; human/AI; опыт и знакомство; версия библиотеки/OS/Python/SDK; длительность всей задачи и установки; число/описание препятствий; помощь; успех или причина остановки. Не включайте токены, .env, личные сообщения или реальные user data. Самоотчёт отмечается отдельно от наблюдаемого прогона. Участник может остановиться без завершения задачи.

## После исходного замера

Сначала сопоставьте одинаковые условия задач, не объединяйте warm/cold install и assisted/blind режимы. Операционные seconds и cognitive lookup time различаются. Назначайте ориентиры времени и допустимых затруднений только после фактических human/AI результатов; при маленькой выборке это provisional targets, не статистическое обещание. Задайте follow-up на тех же заданиях после исправлений.

Пункт 020 остаётся pending до замеров обеих категорий и зафиксированных на их основе targets. Независимые другие пункты roadmap продолжаются. Полное исследование 5–8 разработчиков предусмотрено отдельным пунктом 089; это не замена ему.
