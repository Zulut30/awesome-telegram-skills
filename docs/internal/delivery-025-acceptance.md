# Локальная приемка надежной доставки 0.25.0

5 ноября 2026 приняты пункты 32–40 исходного плана. Полная проверка immutable source archive завершилась успешно: 90 этапов, 715 Python-тестов с тремя пропусками по окружению, 61 TypeScript-тест и Chrome. Wheel/tarball установлены в отдельные core/SDK/TypeScript consumer-проекты; выполнены процессные гонки, аварийные рестарты и HTTP-прием. Проверка покрытия дала 92,03% строк, пять обязательных модулей имеют полное покрытие ветвей.

[Машинная сводка](delivery-025-acceptance.json) содержит hashes артефактов, source tree/commit и сопоставление требований с тестами. Полные логи и отчет находятся в `output/pattern-library-0.25.0/` исходного checkout. Исходный commit `ab1a432` опубликован в `codex/production-roadmap`; после исправления сообщений тот же tree имеет commit `6599505` в `codex/production-v1`.

| Пункты | Принятый результат |
| --- | --- |
| 32 | Проверка текущих прав и единственная SQLite бизнес-запись при повторах и конкуренции |
| 33–34 | Аутентифицированный HTTP-прием после durable receipt, версии, карантин и fenced recovery |
| 35–36 | Общая транзакция бизнес-записи и намерения отправки, conservative retry и сверка неизвестного итога |
| 37–38 | Сохраненные расписание, согласие, ограничения, flood cooldown, отмена и восстановление |
| 39–40 | Остановка приема и завершение owned работы; безопасная корреляция, задержки, повторы и отказы |

Все компоненты остаются experimental. Эта приемка относится к локальному контракту перечисленных пунктов. Реальные Telegram-клиенты, платежные кабинеты, люди и production-пилот недоступны; соответствующие исходные требования остаются открытыми. Глобальная приемка CI, поддержка и выпуск 1.0 здесь не принимаются.
