# Независимая проверка 42 навыков

Для каждого навыка замороженного набора 0.28.0 получено воспроизводимое решение:
42 принятых сценария, 117 проверочных случаев. Проведены шесть отдельных сессий
`fork_turns=none`; принятые решения получены в пяти из них. Модель одна —
`gpt-6.1-sol`. Исполнители выбирали навык по описанию, получали только выбранный
каталог с LICENSE/references и работали с установленными точными пакетами.
[Машинный отчет](skill-evaluation-088-acceptance.json) связывает ответы, навыки,
артефакты, происхождение сессий и фактические результаты.

## Что показали попытки

Первый judge принял 21 из 42 ответов, но сам содержал дефекты: неверный формат
context, повреждение UTF-8 в Windows, неполные fixtures и ограничения наблюдения.
Исходные результаты сохранены. Независимый аудит исправил проверяющий контур;
повторная оценка тех же неизмененных ответов подтвердила 40 из 42. Два отказа
из-за неподдерживаемых импортов сохранились.

Новые исполнители без истории решили другие задачи для этих двух навыков.
T043 прошел шесть случаев планирования; T045 — шесть случаев выбора установленного
SDK с сохранением серверного контекста. Они получили полный публичный индекс
420 API, поэтому условия отличаются от первого набора. T044 остался
`boundary-not-assessed`: собственный диагностический child остановлен guard,
хотя публичное задание явно его не запрещало. Его результат не заменен на PASS.
В T045 ограничение текущим процессом опубликовано заранее; отдельно проверено
наблюдение вызовов в рабочих потоках.

точный исходный ZIP, wheel/tgz, задачи, judges, ответы, результаты и отфильтрованную
видимую историю. Проверены все 388 контрольных сумм и соответствия
source→delivered. SHA-256 архива:
`eb24ea0ee2d1918570e939f94df4c8506b4ac6dfbd2e815003cdb9c428a670b5`.
README архива описывает replay в новых consumers. Replay готового ответа не
является новой независимой сессией модели. Архив не опубликован внешним сервисом.

Это ограниченная проверка решений на source
`92a9d151dc57d85cc5f1eb614f9980e808b36b59`, а не универсальная оценка качества
или приемка будущего 1.0 RC. Общая файловая система не является OS sandbox;
внутренние рассуждения, системные инструкции, `.env`, master sessions и значения
canary в архив не включены. Реальные Telegram-операции, платежные кабинеты,
физические устройства, человеческое usability-исследование и пилоты не проверены.
Правильный `not_run` в задании device QA не означает прохождения device-приемки.
