# Проверка набора

Обновлено: 3 октября 2026 года (Europe/Warsaw); проверка начата 2 октября. Среда: Windows, Python/Node.js. Текущий набор: 41 навык, Python для ботов и backend, TypeScript для Mini Apps. Общая библиотека компонентов обновлена до 0.3.0; ее consumer/runtime проверки описаны отдельно от исторического аудита 40 навыков.

## Формы ботов 0.3.0

[Отчет формы](form-tools-review.md) фиксирует проверки в настоящем Dispatcher с fake transport, concurrent confirms, стабильный ID после commit/ошибки и реальную SQLite запись. Навык code-patterns содержит переносимый локальный рецепт. В этом проходе не проводилось независимое испытание выбора/поведения агента; готовый рецепт проверяется как композиция публичного API.

Финальные установленные wheel/tarball прошли 56 Python tests и 15 TypeScript tests; Mini App — 141 browser assertion в 14 сочетаниях размера/темы. Дополнительно CLI copy 5 файлов code-patterns и исполнение его form recipe через установленный wheel сохранили существующий /ping и одну SQLite запись после повтора. Валидатор 41 навыка и 16 root tests прошли. Итог поставки (`output/pattern-library-0.3.0/distribution-report.json`, локальный артефакт), переносимый рецепт (`output/pattern-library-0.3.0/recipe-evidence.json`, локальный артефакт).

## Инструменты ботов 0.2.0

Добавлены шесть групп компонентов для конфигурации, кнопочных меню, пагинации, статических команд, polling и synthetic test transport. [Отчет](bot-tools-review.md) описывает контракты, проверку установленного пакета и границы live Telegram. TypeScript API сохранен; номер поставки согласован с Python. Проверки прежних версий ниже остаются историческими результатами.

## Библиотека 0.1.1

[Повторная проверка библиотеки](component-library-hardening.md) воспроизводит ошибки и подтверждает исправления через финальные wheel/tarball в новых consumer-проектах. Команда `python scripts/verify_pattern_packages.py` после `npm.cmd ci` сохраняет версии, логи этапов, SHA256 артефактов и browser matrix. Реальные Telegram-клиенты и платежные провайдеры в этой проверке не участвовали. Проверка первого выпуска ниже остается историческим результатом 0.1.0.

## Проверки набора до расширения с 33 до 40

Библиотека 0.1.0 и новый навык отдельно проверены через реальные wheel/tarball consumers, 27 пакетных тестов, 136 browser assertions и независимые приложения. [Отчет](component-library-review.md) содержит команды, найденные исправления и фактические границы; числа ниже относятся к прежним этапам.

- Валидатор набора: 33 навыка прошли проверку frontmatter, имен, UI-метаданных, локальных ссылок и синтаксиса Python. Локальные ссылки навыков остаются внутри переносимого каталога.
- Официальный `quick_validate.py` из skill-creator: 33 из 33 навыков прошли проверку в UTF-8 режиме Python. Результат расширения: official-validation.json (`output/quality-extension/official-validation.json`, локальный артефакт).
- Тесты установщика: 12 из 12 прошли, без пропусков. На Windows проверены directory junctions для запрета перенаправления назначения и ссылок внутри исходного навыка.
- Парсер индекса API: 4 из 4 тестов прошли. Проверены отделение методов и типов от prose, вложенный markup параметров, ошибка вместо документации и дубли определений. Итого 16 тестов, без пропусков.
- Скрипт обновления индекса выполнил реальный HTTPS-запрос к официальной документации без credentials. Сохранены Bot API 10.3, 185 методов, 400 типов, имена полей, ссылки, время получения и SHA256 источника. Полные описания API не копируются.
- Полный запуск CLI на временном проекте: все 33 навыка и 97 файлов скопированы с побайтовым совпадением. Dry run не создал каталоги; повторная установка завершилась отказом от перезаписи. Результат: installer-roundtrip.json (`output/quality-extension/installer-roundtrip.json`, локальный артефакт).

Ручная сверка инструкций со сценариями [evaluation.md](../evaluation.md): кнопки проверяют entitlement владельца бота; профиль сохраняет неизвестность optional-полей и разделяет маршруты изменения; пользовательский клиент отделяет историю выбранных чатов от Business connection; Crypto Pay не считает update_id уникальным; Platega проверяет shared-secret headers; ЮKassa отделяет capture от успешного списания; новый provider использует собственный callback protocol. Это проверка содержания инструкций; live-интеграции перечисленных функций не запускались.

Независимая проверка поведения выполнена для выбранных сценариев: два TypeScript-приложения записи проверены в Chromium на восьми размерах окна и двух темах; 32 Python теста проверили auth/Crypto Pay на test vectors и fake integrations; отдельный агент выбрал навыки для 32 запросов по descriptions. Найдена ошибка lifecycle и проверено ее исправление. Подробности, артефакты и ограничения: [quality-review.md](quality-review.md).

При расширении с 25 до 33 навыков независимо проверен выбор по descriptions на 28 дополнительных запросах. Это оценка различимости навыков; автоматический загрузчик и исполнение запросов этим тестом не проверялись. Результат: routing-results.json (`output/quality-extension/routing-results.json`, локальный артефакт).

Исполняемые пробы расширения: 27 Python тестов проверили API/SQLite/worker/logging; 17 TypeScript тестов — локализацию, theme tokens и fake location. Родительский browser probe проверил 32 сочетания языка, темы и размера окна. Проверено исправление повторного запроса с тем же adapter и modal keyboard. Подробности: [skill-extension-review.md](skill-extension-review.md).

Команды воспроизводимых проверок:

## Полный повторный аудит 3 октября

Все 33 навыка повторно прочитаны в трех независимых проходах: 97 файлов без пропусков. Девять замечаний к содержанию и источникам исправлены; дополнительно уточнены scope и формулировки. Оценка каждого навыка, точный diff и исходный снимок сохранены в [skill-quality-audit.md](skill-quality-audit.md).

В этом проходе заново выполнены 16 тестов репозитория, 23 frontend contract model tests и 15 SDK/fake-client tests. Отдельная проба aiogram 3.31.0 подтвердила продвижение polling offset при незавершенном handler; это fake transport без Telegram HTTP. Свежая схема Bot API 10.3 содержит те же 185 методов и 400 типов. Валидатор коллекции и официальный quick_validate повторены после правок: результаты (`output/quality-reaudit/summary.json`, локальный артефакт).

Исторические installer roundtrip, TypeScript-приложения и browser matrix выше в этом повторном аудите не запускались заново. Новые офлайн-пробы не подтверждают работу native API, реальные платежи или UI на физических устройствах.

## Расширение до 40 навыков

Структура всех 40 навыков, официальный quick_validate, 16 тестов репозитория и CLI copy 119 файлов проверены при последнем расширении. Полный объем новых поведенческих проб и результатов приводится в [skill-product-extension-review.md](skill-product-extension-review.md).

В независимых рабочих примерах прошли 53 Mini App browser tests (27 поведения/API + 26 visual comparisons), 25 login/admin backend methods, 13 local HTTPS сценариев, 3 Node client tests и 36 subscription/media checks с SQLite и FFmpeg. Родитель повторил основные наборы. Отрицательные JWT варианты и targeted timeout repetitions входят в свой scope и не объявлены новыми уникальными функциями. Найденное уточнение TTL неизвестной операции исправлено в network-recovery и проверено регрессией; temporary baseline review дополнен пояснением.

Текущий снимок, исходники проб, отчеты, hashes и точные ограничения сохранены в summary.json (`output/quality-product-extension/summary.json`, локальный артефакт) и архиве материалов. Исторические проверки выше не суммируются с этими счетчиками.

## Полная проверка всех 40 навыков

Три независимых прохода прочитали 119/119 канонических файлов; для каждого навыка выполнен отдельный узкий сценарий. Новые пробы: 25 Python tests и 44 browser assertions для Mini Apps/локализации, 46 SDK/fake-transport checks, 15 backend contracts с SQLite/HTTP/crypto/FFmpeg/process restart. Архитектурный план и матрица недоступных устройств проверены как артефакты, без выдуманных runtime результатов. Родитель свежим запуском проверил прежний Mini App пример: 53/53 (27 поведения и 26 сравнений скриншотов).

Слепой выбор по descriptions: 55/56 основных выборов совпали с заранее заданными критериями; в оставшемся запросе dialogs выбран вместе с debugging. Нужный навык есть во всех 56 наборах, запрещенных расширений scope не обнаружено. Это проверка выбора агентом по описаниям, а не автоматического загрузчика.

Уточнен полный OIDC audience-контракт и обновлен опубликованный callback статуса Platega. Пять signed JWT случаев и SQLite classification повторены родителем после правок; независимое перечитывание признало уточнения достаточными. Полная таблица 40 навыков, исходные неуспешные fixtures, hashes и ограничения: [skill-full-check.md](skill-full-check.md).

## Что остается проверить в целевом продукте

Остальные сценарии [evaluation.md](../evaluation.md), работа бота в Telegram, UI и bridge на физических устройствах/целевых клиентах, настоящий backend и платежные test environments. Выполненная выборка не заменяет проверку каждого навыка и целевого продукта. Набор содержит инструкции и помощники; приложение бота, Mini App и production payment adapters разрабатываются в целевом проекте.

Все 40 навыков представлены в переданном текущему чату каталоге. Это подтверждает их видимость; автоматическая активация и выполнение каждого навыка загрузчиком отдельно не проверены. Независимые испытания читают выбранные SKILL.md непосредственно из файлов. Доступность в других агентах требует собственной проверки.

Прямая новая страница Crypto Pay вернула HTTP 403. Для ее протокола использован более старый индексированный снимок официальной страницы; перед live-интеграцией требуется свежая сверка. Остальные использованные первичные источники и границы проверки перечислены в [sources.md](../sources.md).

Логи и снимки с путями `output/…` — локальные артефакты исторических проверок. Они не входят в Git и не доступны в свежем клоне. Для текущей принятой версии смотрите [сохраненную приемку 031](../v1-checks/031.json); для нового прогона выполните `python scripts/verify_pattern_packages.py`.
