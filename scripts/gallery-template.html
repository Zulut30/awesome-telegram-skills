Как читать статусы и версии

Зрелость и доказательства проверки независимы. SDK проверяет построение объектов. Mock исполняет сценарий без Telegram. Справочный фрагмент требует доработки. Веб-превью показывает раскладку; настоящие клиенты здесь не проверяются. Контекст — метка примера, права проверяет приложение. Версия SDK — проверенный снимок; min native API не доказывает поддержку клиентом. Стабильные сценарии 1.0 еще не заявлены.
